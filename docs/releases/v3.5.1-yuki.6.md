# v3.5.1-yuki.6

改进子代理结果投递、动态关注点、主会话演示和上下文排查，并修复 preset 启动校验。

## 主要变化

- **取消默认 30 分钟截止**：新 workflow 默认不限总运行时长，仍可手动停止。已有失败记录不会自动重跑；旧记录恢复时保留原先记录的时长约束。
- **子代理及时回报**：完成报告自动进入主会话，使用持久化投递记录和共享去重游标。等待因新报告结束时，真实工具返回中携带正文，避免主模型只看到“已发送”的回执。
- **非紧急发现也能投递**：新增 `finding`，用于证据、适用条件、不确定性、假设变化和对其他任务的影响。纯进度和重复回执仍应省略。
- **动态评估提示**：新报告触发临时关注点；单纯 wait 或查询状态不再算作已评估。模型可按内容决定回复、验证、调整任务或静默继续，用户的新指令优先。
- **修复 preset 校验**：参数预处理不再补入 `script: undefined`，避免合法 `{ preset, args }` 被 `oneOf` 拒绝。验证覆盖实际 Pi CLI 的加载、预处理和校验顺序。
- **完整主会话演示**：`/workflows-demo` 使用固定只读样例，演示真实工具调用、预期错误恢复、两个真实子代理、逐个回报和汇总；会使用模型 token。旧离线弹窗保留为 `/workflows-demo preview`。
- **上下文可观测性**：增加按会话记录的请求追踪，区分 workflow 投影、最终请求、响应状态和模型后续动作。日志滚动限大小，截断与未观测状态明确标记。
- **稳定性和界面**：修复 steer 连续性、重载去重、错误返回显示、取消边界及多处运行时状态一致性问题；精简报告头并改善进度面板。

## 安装或更新

需要 Node.js ≥22.19.0，与当前 Pi SDK 的要求一致；CI 已同步使用 Node 22。

```bash
pi install git:github.com/YukiRa1n/pi-dynamic-workflows@v3.5.1-yuki.6
```

本版包含运行时更新，请先等活动 workflow 结束，再完整重启 Pi。单独 `/reload` 可能保留旧运行时对象及其默认值；重启后新 workflow 使用不限时默认值和新的投递类型。

最终请求追踪需要另行应用仓库中的 `scripts/patch-pi-request-trace.mjs` 本机 Pi 宿主补丁，再完整重启 Pi。单独安装扩展不会修改宿主；没有最终采集点时，日志会明确显示未观测。先等活动 workflow 结束再重启。

本地诊断版本默认开启日志。日志包含会话与项目文字，并省略认证字段及二进制数据；可用 `/workflow-trace status` 查看位置，或 `/workflow-trace off` 关闭。请求已记录、HTTP 成功均不等于模型已充分理解。
